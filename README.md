# night-beach

A Claude theme mod that puts a moonlit beach behind the conversation in the Claude desktop and mobile apps: a starry sky, a glowing full moon, its light shimmering on gentle waves, surf on the sand and a swaying palm. It also switches the app to a matching dark ocean-blue palette with lightly frosted panels so text stays readable.

## Install

At the prompt of a terminal Claude Code session:

```
/plugin install night-beach --marketplace jamieharper0798/night-beach
```

Answer `y` to add the marketplace, then pick the user scope so it applies to every session.

From a shell:

```bash
claude plugin install night-beach --marketplace jamieharper0798/night-beach
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `jamieharper0798/night-beach`, then Add plugin.

This repository is private: installing needs read access on GitHub and a git credential for github.com on the machine (an SSH key, or `gh auth login` then `gh auth setup-git`).
